# Rusty doc の使い方

ディレクトリベースで  
md ファイルはこんなふうに自動でhtmlに変換されて配信される  
以下のエンドポイント  
- `raw/<path>`: 生データを受け取る HTTPストリーミング可能
- `/<path>`: raw出なかった場合 mdならhtmlにSSRして配信する

`<path>` がディレクトリだった場合、`/<path>`エンドポイントでは ディレクトリページを生成します。  
またディレクトリページではそのディレクトリの`index.md` が下に挿入されます。
