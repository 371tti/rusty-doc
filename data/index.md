# Rusty Doc へようこそ。

このサイトは、Rust で書かれたドキュメント生成・配信ツールの実験的プロジェクトです。Markdown から読みやすいページを生成し、軽量で高速な表示を目指しています。

主な特徴:
- Markdown をベースにしたシンプルな記事管理
- 余計な依存を抑えた軽量なページ生成
- ナビゲーションやテーマを最小限の設定で拡張

これから開発中の機能や記事を順次追加していきます。まずはサンプル記事をご覧ください。
